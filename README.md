# CEN-EVALV1
CEN-EVALv1 est un projet de logiciel éducatif conçu pour faciliter la gestion, le traitement et le suivi des évaluations scolaires dans les écoles. L’objectif est de proposer un outil simple, moderne, accessible sur téléphone et ordinateur, particulièrement adapté aux réalités des établissements scolaires où la connexion Internet peut être faible
